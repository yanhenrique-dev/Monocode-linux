# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful. Harassment, insults, and bad-faith participation are not welcome.

The maintainer may warn, restrict, or ban anyone who makes this worse for others.

Report conduct issues to the maintainer ([yanhenrique-dev](https://github.com/yanhenrique-dev)) via GitHub, or privately if you prefer.
